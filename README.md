# آخرتي – Akhirati

تطبيق أذكار وأدعية لأندرويد وآيفون، مبني بـ Expo (React Native).

## الميزات في الإصدار الأول
- أذكار الصباح والمساء والنوم والاستيقاظ وبعد الصلاة، وأذكار البيت والسفر، وأدعية قرآنية، مع عدّاد لكل ذكر وذكر المصدر.
- الدعاء حسب حالتك: قلق، حزن، امتحان، مرض، رزق، استخارة، توبة، غضب، شكر، سفر.
- اختبر معلوماتك: أسئلة دينية بثلاثة مستويات (سهل، متوسط، صعب) مع شرح لكل إجابة.
- مسبحة إلكترونية مع اهتزاز وعدّاد يومي وكلي.
- المفضلة، ومشاركة أي ذكر أو دعاء.
- مواظبة أسبوعية وسلسلة أيام.
- تذكيرات يومية، ووضع داكن، وتكبير الخط.
- يعمل بدون إنترنت وبدون إعلانات.

## التشغيل
```bash
npm install
npx expo start
```
ثم امسح رمز QR من تطبيق Expo Go.

## البناء
```bash
npx eas-cli@latest build --platform android --profile preview
```

المحتوى الديني من كتاب «حصن المسلم» والقرآن الكريم. يُنصح بمراجعته من مختص قبل النشر.
